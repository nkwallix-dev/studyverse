# Kenny 30 FPS Animation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Kenny's existing normal animation assets with a registered six-appearance, 30 FPS set including a continuous rat feeding sequence.

**Architecture:** A manifest defines action timing and atlas geometry. One canonical pose set is packed and palette-derived into stable paths; elapsed-time frame selection is centralized so presentation and platformer playback agree.

**Tech Stack:** Angular 22, TypeScript, SCSS, Node test scripts, Python/Pillow asset scripts, transparent PNG atlases.

**Spec:** `docs/superpowers/specs/2026-11-22-kenny-30fps-design.md`

## Global Constraints

- Playback rate is exactly 30 FPS.
- Standard, Blue, Green, Red, Rose-Pink, and White share identical geometry and pose timing.
- Persisted `zebra` remains valid and maps to White with black stripes.
- Rat feeding starts with the rat outside the crop and uses the 96-frame phase ranges in the spec.
- Existing physics, hitboxes, controls, fusion equipment, and save compatibility remain unchanged.

## Review Focus

- A 60/120/144 Hz render loop must select identical animation frames for the same elapsed simulation time.
- The first rat-visible frame must enter from the edge; no complete rat may pop into an earlier frame.
- Pink must pass a rose-pink hue check and remain visually distinct from Red.
- White pixels must remain opaque artwork while the background remains transparent; black stripes must survive cleanup.
- Old profiles containing `zebra` and all existing asset URLs must continue to load.
